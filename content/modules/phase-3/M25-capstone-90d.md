# M25 · 90 天毕业大项目

**Day 89–90 | Phase 3 | 项目 P07**

## 1. 项目目标
交付 **个人自动化业务系统** 完整版：跨境/副业真实场景，端到端可演示 15 分钟。

## 2. 会学到什么
- 系统集成验收
- 技术 + 业务双文档
- 演示与交接

## 3. AI 负责什么
- 按 P07 checklist 查漏
- 生成演示脚本与 FAQ
- 答辩 Q&A

## 4. 人需要理解什么

| 概念 | 通俗解释 |
|------|----------|
| **系统集成** | 把 Phase 1–3 所有积木拼成一条完整流水线 |
| **端到端** | 从「扔一张图进 inbox」到「收到处理完的通知」，一路自动 |
| **运维** | 系统跑起来之后的活儿：重启、清队列、看日志、备份 |
| **合规** | 自动化要合法：不撞 API 限速、不爬不该爬的、不冒充用户 |

## 5. 代码理解点

- [ ] 能白板画出全流程（5 个盒子 + 箭头）
- [ ] 能指出系统中「哪个文件是入口、哪个管配置、哪个管日志」
- [ ] 理解 `pipeline.yaml` 的结构与作用（阶段编排）
- [ ] 知道 `trace_id` 在哪生成、在哪使用、如何定位单次任务

## 6. 工程思维

- **可维护 > 炫技**：新人看 README 能跑起来，比代码漂亮重要 10 倍
- **ToS 与合规**：爬虫/自动化需自述边界（频率、数据用途、是否合规）
- **失败设计优先**：系统不是「不会出错」，而是「出错后能恢复」
- **文档即交付物**：没有 RUNBOOK（运维手册）不算交付

## 8. 常见 AI 错误
| 错误 | 表现 | 你怎么发现 |
|------|------|------------|
| demo 造假 | 手动步骤隐藏 | 录屏里能看到手动复制文件的瞬间 |
| 只写功能不写文档 | 交付时只有代码 | 让同事（或朋友）试着跑，2 分钟内跑不起来 |
| 过度工程 | 加 K8s/消息队列/Web 后台 | diff 里出现你 90 天没用过的技术栈 |
