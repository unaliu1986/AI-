# AI 代码审查清单

审查 AI 生成的代码时，逐项勾选。

## 安全

- [ ] 无硬编码 API Key / 密码
- [ ] `.env` 在 `.gitignore` 中
- [ ] 无 `eval()` / 任意 shell 注入
- [ ] 文件操作限制在指定目录内

## 正确性

- [ ] 路径用 `pathlib` 或 `os.path.join`，非字符串拼接
- [ ] 网络请求有 timeout
- [ ] 异常被捕获且有意义的错误信息
- [ ] 边界情况：空文件夹、网络断开、重复运行

## 可维护

- [ ] 函数单一职责，主流程可读
- [ ] 魔法数字提取为常量或配置
- [ ] 有 logging，非仅 print
- [ ] README 说明如何运行

## AI 特有坑

- [ ] 引用的库/函数真实存在（让 AI 给文档链接）
- [ ] 无「占位符」未替换（TODO、your_api_key_here）
- [ ] 版本与本地环境一致
- [ ] 未删除你已有的 working code（diff 审查）

## 审查结论

- [ ] 通过，可合并
- [ ] 需修改：___
- [ ] 拒绝，重写原因：___
