# M10 · 30 天毕业项目

**对应天数**：Day 25–30 | **阶段**：Phase 1  
**关联项目**：[P02-capstone-30d.md](../../projects/P02-capstone-30d.md)

## 1. 项目目标
交付一个 **你真实工作会用** 的自动化小系统（二选一或自定）：
- A. 跨境素材 inbox：下载→分类→重命名→日报
- B. 多 API 仪表盘：汇率+天气+自定义 webhook → 每日 CSV

## 2. 会学到什么
- 从 0 写需求文档
- 多模块集成（watcher + api + log + config）
- 写 README 给他人用

## 3. AI 负责什么
- 按你的需求文档分 milestone 实现
- 生成 README 与运行脚本
- 答辩式 Q&A 帮你发现漏洞

## 4. 人需要理解什么
你是 **产品经理 + 质检 + 运维**，AI 是开发。

## 5. 必须掌握的代码理解点
- [ ] 能画出系统数据流（inbox → 处理 → 输出）
- [ ] 能解释每个文件的职责

## 6. 必须掌握的工程思维
- **Scope 控制**：30 天版本求能跑，不求完美
- **文档即交付物**：没有 README 不算完成

## 7. 推荐提问方式
```
我要做 30 天毕业项目，需求文档如下：（粘贴 templates/project-kickoff.md 填好的内容）
请拆成 4 个 milestone，每个不超过 200 行新代码。
先输出架构图（mermaid）和文件列表，我确认后再写 M1。
```

## 8. 常见 AI 错误
| 错误 | 表现 | 你怎么发现 |
|------|------|------------|
| scope 膨胀 | 加数据库、加 Web UI | 检查 diff，新增文件超过 5 个 |
| 无验收标准 | 做完不知道算不算完 | 问 AI「怎么算完成」AI 回答模糊 |
